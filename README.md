# Community Wallet

Community-based financial infrastructure and shared wallet platform.

## Tech Stack
- React 19 + TypeScript
- Tailwind CSS
- Vite
- Lucide React (icons)

## Quick Start

```bash
npm install
npm run dev
```

App runs on http://localhost:5173

## Architecture

### Components
- Dashboard with wallet balance display
- Transaction history with filtering
- Community member directory with quick send
- Real-time balance updates

### Features
- Wallet balance tracking
- Send and receive funds
- Transaction history
- Community member management
- Quick send to favorites
